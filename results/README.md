# Results / 结果

- `set S/` contains historical raw results for the Set S benchmark.
- `set S/summary.csv` is generated by
  `scripts/analysis/summarize_results.py`.
- New reproducible experiments are written to `artifacts/experiments/`.

The generated result files are intentionally ignored by Git.

- `set S/` 保存 Set S 基准的本地历史原始结果。
- `set S/summary.csv` 由 `scripts/analysis/summarize_results.py` 生成。
- 新的可复现实验统一写入 `artifacts/experiments/`。
